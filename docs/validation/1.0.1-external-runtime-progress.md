# Cinemarr 1.0.1 external runtime validation

2026-09-28. Implementation completed on `fix/1.0.1-external-runtime`, based on `3ad77156aaa4edbc0e435478246bd188799b3fe7`. This record describes local implementation validation; GitHub Actions records subsequent CI results for each commit. Neither is publication or CurseForge moderation approval.

## Delivered behavior

- Retains JavaCV/JavaCPP FFmpeg decoding with Java-only distributable JARs.
- Automatically finds complete matching local libraries; `nativeRuntimeDirectory` is an authoritative override. `nativeRuntimeMode` supports `local-only` and `disabled`.
- Validates pinned local packages or extracted libraries for Linux x64, Linux ARM64, and Windows x64. Local import uses bounded extraction, checksums, locking and an instance cache. It extracts no Java classes or command-line programs.
- Performs no native dependency downloads. Missing libraries leave Minecraft usable; retry is possible before native initialization, and replacing initialized libraries requires restart.
- Defers JNI initialization until decoding, preserves scoped JavaCPP properties and verifies explicit native paths. Settings expose folder/retry actions and current error details.
- Includes [manual installation and upgrade instructions](../INSTALLING_DECODER_LIBRARIES.md), Linux host dependencies, release notes, and recursive native-payload checks for every artifact.

## Diagnosed interruptions and limits

The Windows evidence runner had an unset archive variable after successful decoding; its assignment is fixed. ForgeGradle requires configuration caching disabled. An obsolete NeoForge lock membership and legacy's hard-coded version were corrected. Legacy native test packages opt out of Java deobfuscation so their pinned bytes remain unchanged. Cold build/test dependency preparation failures were addressed separately from product tests. Intentional host maintenance interrupted an ARM confirmation and a Plex attempt; these interrupted runs are not counted as passes. Modern tooltips now refresh after asynchronous library actions.

This covers all artifact packaging, representative production client loading, software native decoding on the supported native platforms, and one real-Plex client/server profile. It does not claim all 21 runtime profiles were launched, a new physical-GPU certification matrix, physical ARM testing, or full Windows Minecraft acceptance. No artifacts have been published and no moderator messages were sent.

Focused reproduction: `python3 scripts/test-external-runtime.py --dependencies /path/to/local/test-dependencies`. The script documents required local JARs and does not download files or build Minecraft mods. Local execution logs and source provenance are under `build/external-runtime-validation/` and `/tmp/cinemarr-runtime-spike/`.
