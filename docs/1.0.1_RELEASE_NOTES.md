# Cinemarr 1.0.1 — development release notes

Cinemarr retains its existing video decoder while removing all native binaries from its distributable mod JARs. Players must now supply matching JavaCPP and FFmpeg libraries locally; dedicated servers require no decoder libraries. There are no automatic dependency downloads.

- Detects complete compatible local installations and previously imported instance caches.
- Adds `nativeRuntimeDirectory` for an explicit path and `nativeRuntimeMode` (`local-only` or `disabled`).
- Validates user-supplied native archives and extracted libraries against pinned checksums before loading.
- Defers native initialization until playback and reports missing dependencies without preventing Minecraft startup.
- Adds local library folder/retry actions and a recursive release guard against embedded native payloads.

See [installation instructions](INSTALLING_DECODER_LIBRARIES.md) before upgrading from 1.0.0. Protocol 11 and screen saves are unchanged. Implementation and bounded validation are complete; see the [validation record](validation/1.0.1-external-runtime-progress.md) for coverage and limits. This update has not been published or accepted by CurseForge moderation.
