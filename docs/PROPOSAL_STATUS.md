# Proposal implementation status

This file maps the checked-in `Proposal` to implementation and acceptance evidence. The local 1.0.1 candidate is release-ready but unpublished: the corrected production Plex path passed its decisive two-client controller/UI gate, and the post-fix build/test/artifact matrix passed all 21 runtime profiles and all 16 canonical JARs.

| Proposal area | Status | Implementation / evidence |
| --- | --- | --- |
| Standalone sibling mod and Jammarr-aligned matrix | Implemented | Independent `cinemarr` mod ID and 16 artifacts covering Forge 1.7.10 plus Fabric/Quilt, Forge, and NeoForge families for 1.20.1, 1.20.2, 1.21.1, 26.1.2, and 26.2. |
| Server-owned Plex credentials and allowlisted libraries | Implemented | Canonical server/library files, environment token override, permission/rating filters, and client models that exclude the Plex URL/token. |
| Planar screens | Implemented and tested | Solid rectangles, squares, odd dimensions, and straight lines are the default; connected masks/holes are available through `allowIrregularScreens`. Persisted invalid registrations are pruned without force-loading chunks. |
| Screen and stream limits | Implemented and tested | Configurable minimum/maximum pixels and dimensions, eight globally counted TVs per owner, and four concurrent open Plex streams. Idle, paused, and dormant session names consume no stream slot. |
| Construction components | Implemented and packaged | Screen Pixel, TV Controller, casing, speaker, TV Remote, and redstone receiver registrations, assets, translations, and survival recipes across the target matrix. The Remote uses the controller path; an adjacent powered receiver toggles playback on each rising edge. |
| Quick TV shortcuts | Implemented and runtime-tested | Configurable 144p through 8K progressive recipes and bounded 16:9 prefabs. Every runtime profile built the 144p acceptance TV and persisted its 16x9 / 256x144 contract. |
| Fit, fill, stretch, odd dimensions, and masking | Implemented and tested | Exact client presentation transforms, codec-safe even rendition requests, final client resampling, cropping, and per-pixel visibility masks. |
| Plex browsing and controls | Implemented and tested | Movies, search, shows/seasons/episodes, continue episode, queue/now playing, stream selection, presentation mode, permissions, play/pause/seek/skip/stop, and local volume/screen-disable controls. |
| Watch parties and lifecycle | Implemented and tested | Named sessions share one timeline/transcode. Breaking or unregistering one TV leaves other viewers running; removing the final TV checkpoints paused dormant state and closes its Plex stream. Owner/operator recovery commands leave blocks intact. |
| Bounded media relay | Implemented and tested | Server-confined HLS, 16 KiB payloads, SHA-256, pull/ack windows, rate and lead limits, keyframe-aware seeking, rolling cache, and viewer-driven shutdown. |
| Client video/audio | Implemented and matrix runtime-tested | One decoder/dynamic texture per visible session, batched masked screen rendering, positional audio from the nearest screen point, clock filtering, and drift correction. Modern clients quality-gate their bounded startup clock sampling, map the shared media position to a server-owned epoch, and compensate measured OpenAL physical output latency inside a silent preroll; representative final-implementation captures stayed within 0–70 ms. All 21 profiles have deterministic two-client visual/audio evidence, including Quilt 26.2 with Mod Menu after its clientbound error-response codec path was exercised; Forge 1.7.10 passed consecutive fresh physical captures after its LWJGL 2 adapter began confirming backend progress inside a silent preroll. |
| Native decoder packaging | Implemented with bounded evidence | LGPL notices and Linux x64/arm64 plus Windows x64 JavaCV/FFmpeg classifiers are packaged. User-selectable decode modes are software, auto, and VAAPI; platform-specific candidates remain internal to auto. Linux software/auto real-client gates pass all 21 profiles, ARM64 software/fallback smoke passes, and through-4K standalone evidence covers AMD and Intel VAAPI plus a Windows P600. Forge 1.7.10 has substantive native Windows auto evidence, but its corrected wrapper was not rerun green; NeoForge 1.21.1 and Fabric 26.2 native Windows clients and ARM64 GPU acceleration are untested. Software remains the default because no host met every performance threshold. |
| Live Plex feasibility spike | Passed replacement acceptance | The old smoke omitted `metadataDetails()` and issue #1 exposed its boolean-stream failure. The replacement covers boolean/numeric selection, production metadata and HLS resolution, native H.264/AAC decode, real in-game controller selection, two identifiable real clients, physical audio synchronization at 0 ms measured lag, and clean Plex/process/credential teardown. |
